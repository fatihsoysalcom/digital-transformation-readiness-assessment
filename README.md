# Digital Transformation Readiness Assessment

This Python script provides a simple readiness assessment for digital transformation. It evaluates factors like technology investment, employee training, system modernization, and strategic definition to gauge a company's preparedness.

## Language

`python`

## How to Run

Save the code as `digital_readiness.py` and run it from your terminal using `python digital_readiness.py`.
